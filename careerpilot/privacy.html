CareerPilot

Privacy Policy

Last updated: 8 November 2026

Overview

CareerPilot is a personal job-search assistant operated by Tom Reilly. It is not currently offered as a public service.

Google Account Access

CareerPilot uses Google OAuth to obtain authorised access to Gmail for processing job-alert emails.

The same Google Cloud project also contains a separate OAuth client for a personal rclone Google Drive connection, used to access and manage files in the account owner's Drive.

Purpose of Access

Google account access is used for personal job-search workflows and personal file management, respectively.

Data Storage and Processing

Application data may be processed and stored in the account owner's computing environment. Any use of external processing services must be consistent with the application's actual configuration.

Data Sharing

These integrations are intended for personal use, not for selling Google account data or providing access to unrelated users.

Access and Revocation

Google OAuth access can be revoked through the account owner's Google Account security settings.

Contact

For privacy enquiries, use the support email shown on the application's Google OAuth consent screen.
